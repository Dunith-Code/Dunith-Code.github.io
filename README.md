# Dunith Desitha Athukorala · Portfolio

Welcome to my personal portfolio website, a terminal‑style, dark‑themed single‑page application showcasing my work as an Instrumentation & Automation Engineering Technology undergraduate, AI/ML enthusiast, and full‑stack developer.

🔗 **Live Site:** [dunith-code.github.io](https://dunith-code.github.io)

## 📖 Overview

This portfolio is designed to feel like a developer's terminal, combining a clean, technical aesthetic with interactive elements that highlight my projects, skills, and professional journey. It serves as a central hub for recruiters, collaborators, and anyone interested in my work.

**What you'll find:**
- **Terminal Hero** — `cat ~/.dunith/about` reveals my bio, role, passion, and goals
- **Projects** — 10+ projects spanning AI/ML, IoT, embedded systems, full‑stack development, and data analysis
- **Skills** — categorized by AI/Data Science, Instrumentation, IT/Full Stack, and Industrial Automation
- **Articles** — my "Learning the Loop" series (ML/DL/RL concepts explained)
- **Volunteering & Club Positions** — leadership and community involvement at University of Colombo
- **Artworks & Workshops** — creative and educational work
- **Contact** — email, LinkedIn, GitHub, Behance, and resume download

## 🚀 Local Development

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)
- (Optional) Python 3 for local server

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dunith-Code/Dunith-Code.github.io
   cd Dunith-Code.github.io
   ```

2. Open directly in browser

- Double‑click index.html, it works immediately.

3. Serve with a local server (recommended for best experience)
    ```bash
    python -m http.server
    ```

4. Edit and preview

- All content is in index.html, edit it directly.
- Refresh the browser to see changes.
